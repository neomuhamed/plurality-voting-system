PLURALITY VOTING SYSTEM

THIS VOTING SYSTEM USES cs50.h LIBRARY FOR get_int and get_string FUNCTIONS.

HOW TO USE:
PROGRAM USES COMMAND LINE ARGUMENTS TO GET CANDIDATE NAMES.
EXAMPLE: ALICE, CHARLIE, BOB
THEN IT PROMPTS USER TO TYPE HOW MANY VOTERS ARE THERE, I.E. 5 VOTERS.
AFTER THAT WE GET 5 PROMPTS (FOR 5 VOTERS) TO TYPE THEIR FAVOURITE CANDIDATE'S NAME.
PROGRAM RETURNS WINNER THAT HAS MOST VOTES.
